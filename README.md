# Neovim Configuration

Personal Neovim configuration built with Lua for a fast, minimal, and productive development environment.

## Features

- Lua-based configuration
- LSP support
- Autocompletion
- Syntax highlighting
- Git integration
- File navigation
- Fuzzy finding
- Code formatting and linting
- Modern development workflow

## Requirements

- Neovim
- Git
- A Nerd Font
- Language-specific tools and runtimes
